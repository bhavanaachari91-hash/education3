# edu.com Website

A premium educational institution website built with **React** and **Node.js**.

## Features
- **Dynamic Navigation**: Responsive navbar with glassmorphism.
- **Academic Departments**: Detailed showcase of CS, Electrical, Electronics, Mechanical, and Civil departments.
- **Global & Local Courses**: Tabbed overview of International and Domestic programs.
- **Faculty & Student Stats**: High-impact hero section with key statistics.
- **Admission Form**: Functional contact form integrated with an Express backend.
- **Premium Design**: Modern aesthetics using Vanilla CSS, Google Fonts, and animations.

## Tech Stack
- **Frontend**: React.js, Vite, Vanilla CSS.
- `server.js`: Handles POST requests from the admission form and manages data.
- **Backend**: Node.js, Express, CORS.

## Getting Started

### 1. Setup Backend
```bash
cd backend
npm install
npm start
```
The backend will run on `http://localhost:5000`.

### 2. Setup Frontend
```bash
cd frontend
npm install
npm run dev
```
The frontend will run on `http://localhost:5173`.

## Folder Structure
- `/frontend`: React application (UI/UX).
- `/backend`: Express server (API/Database).
